- **#1 (HIGH)** `remapPointInverse` gated viewRegion on DISPLAY x not BASE — tail points riding growth past
  xMax failed to invert (corrupts drag/new/select while a width stretch is active on a **multi-view** sheet).
  Farmed the fix to Fable (base-preimage gating via `invertOnAxis`); harness 28/28.

  contamination. Fixed: abort+clearTimeout in the svgUrl reset AND an unmount cleanup effect.

  stale-write guard.
- **#5** PDF date was a machine timestamp → `formatDisplayDate` (YYYY-MM-DD). **#7/#13** cascade pill
  overlapped the markup toolbar + notice shared the stretchWarning slot → one stacked top-center container.
  **#11** markup `<text>` got `fontFamily`. **#12** PDF header title/fields `clip()`ped.

would fire the dim-save effect with empty edits and WIPE persisted `dwg_dim_edits`; multi-sheet-only, needs

## Verification lessons / gotchas (session 9)

- **preview MCP tab-split:** `preview_eval` can land on `/` while another tab is `/editor`. Re-navigate the
  eval context (`location.href = '/editor?project=…'`) and confirm `location.href` before trusting DOM reads.
- **quickAdjust is CASCADE-FREE** — only `handleDimSubmit` (inline dim editor) fires `callAiCascade`. So the
  sidebar `+1'` quick-adjust is the DETERMINISTIC way to make a stretch in QA (no AI noise). To exercise the
  cascade (pending pill / warn banner), use an **inline** dim edit (click a dim in the SVG → editor → ✓).
- **Silencer quick-adjust is a no-op** — its dim has no mapped stretch block. Use **4000 Stack** or SCR Duct
  to make a real (viewBox-growing) stretch.
- **Selecting a component SWAPS the sidebar to a detail panel** (hiding the component list) — click the ✕ to
  deselect and get the list back before selecting another component.
- **Scripted markup draw:** neutralize `Element.prototype.setPointerCapture` to a no-op, then dispatch
  pointerdown/move/up on `[data-elf-markup]` with ~80ms between events.
- **Verifying a compressed PDF's content:** with `compress:true` the text is in FlateDecode streams (not
  greppable). Inflate them in-page with `DecompressionStream('deflate')` (trim trailing EOL bytes before
  `endstream`), then grep. Page count is visible in the raw bytes (`/Count N`, `/Type /Page`).
- **`curl` is not on this shell's PATH** — smoke-check prod with `node -e "fetch(...)"`.
- Bash cwd resets to the Google Drive path between calls — always `cd /Users/mike/dev/EnergyLinkFlex` (or use
  absolute paths).
