## What the Unified 2D Scoping engine does (the deep #3 / Package B fix)

**Problem:** a width (X) edit scaled the *full-height* X-band, ovaling vertically-stacked neighbours
(deep #3) and any detached detail (Sheet_3 skid). **Fix:** scope SCALING to the target component's
cross-axis band; hold everything else rigid; downstream still translates by the map tail.

- **U1 `computeComponentBand`** (`src/lib/dwg/dim-geometry.ts`) — target's `{aRange, crossBand}` from
  real dim-block geometry.
- **U2 (Fable-built, in `svg-stretch.ts`)** — `StretchParams.crossBand`; joins the `applyMultiStretch`
  grouping key (`bandKey`) so different-band same-axis specs are auto-disjoint; per-element, out-of-band
  elements ride `annTranslate` (identity in/before the zone, `axisGrowth` downstream = invariant I2).
- **U3 `detectDetachedAssemblies`** (`src/lib/dwg/detached.ts`) — CONSERVATIVE cross-axis gap detector
  (binned-density corridor + compactness + substantial-side gates). Honest limit below.
- **U4 (wiring in `svg-drawing-canvas.tsx` `applyAllStretches`)** — sets `crossBand` from U1 **only when
  the component has a real cross-axis dim** (else undefined → today's full-band behaviour, so an edit
  never under-scales); high-confidence detached-in-band → non-blocking "Detached details present —
  review manually" WARN.
