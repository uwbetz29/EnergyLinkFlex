EnergyLink FLEX (ELF) is a **sales-configuration tool** for an engineering firm that sells
**SCR/CO catalyst systems** (exhaust scrubbers for gas-turbine mini-power-plants; TITAN PGM
130 base design). A salesperson adapts a base CAD drawing (taller stack, bigger silencer,
longer duct) to a new customer's site, producing a drawing "good enough for a sales sign-off."
**Not a CAD tool** — speed + clarity over precision. Real multimillion-dollar bids depend on
the output being correct.

blocker is RESOLVED.** In-browser on the running app I verified: upload Sheet_2 → WASM parse →

multi-dim stretch → clean render. Along the way, live QA caught and I fixed a real crash.

## The Fable operating model (reusable methodology — see memory `fable-operating-model`)

**Contract & verify.** Opus = general contractor (full context, cheap). Fable = specialist for
the hard, uncertain ALGORITHM only. The ROI lever: make Fable's output cheap to verify.
1. **Contract** — brainstorm → spec (independently reviewed by a subagent, 2 rounds).
2. **Own verification** — Opus writes a **black-box acceptance harness**, left RED. It's Fable's
   reward signal.
3. **Farm out** — hand Fable a self-contained packet (spec + harness + contract + commands);
   it self-verifies to green inside its own run. Spawn as `agent(prompt, {model:'fable',
   effort:'medium', schema})` via a one-stage Workflow (Agent tool lacks effort control).
4. **Verify independently** — Opus runs the full suite + tsc + lint + a golden on real data
   Fable never saw, reads the diff adversarially, then accepts.
- **Guardrails:** Fable may NOT touch tests/fixtures (anti-cheat, verified via mtimes).
  Durability constraint: only farm out things that become durable deterministic code (no runtime
  LLM). Default effort = medium; escalate only the failing case.
- **Scorecard:** A one-shot success (~98k tokens, no bounce-back). B/C/D not worth it — the
  discipline SAVED wasted spend (B's approach was proven unsatisfiable by a ~30-min probe).
