## Verification lessons / gotchas (session 8)

- **Blob question is closed** — do not re-chase "black blobs" on Sheet_2; the remaining dark is real equipment
  (verified: top-10 densest black clusters all varied/structural in `g#*Model_Space`; densest = a fan assembly).
- **Preview MCP tab split:** `preview_eval` and `preview_screenshot` sometimes target different tabs (one lands
  on `/`, the other on `/editor`). Re-navigate the eval context and confirm `location.href` before trusting
  DOM reads; screenshots may show a different tab than your eval.
- **Dimension text inputs are flaky to script** (React controlled inputs). To create undo/persist history in
  QA, select a component and click a **quick-adjust button** (`+1'` etc.) — buttons script reliably; text
  typing does not. After a `.click()`, **read state after a beat** (React re-renders async).
- **Turbopack HMR staleness:** editing a `useEffect` dependency array live can throw a bogus
  "final argument passed to useEffect changed size between renders" console error (server serves a stale
  module). It is NOT a real bug — a full dev-server restart (`preview_stop`+`preview_start`) clears it.
- **`curl` is not on this shell's PATH** — smoke-check prod with `node -e "fetch(...)"` instead.
- The 44MB SVG renders as a large clipped `<svg>` (parent `absolute inset-0`) plus a minimap copy; there are
  multiple drawing SVGs with different coordinate systems. Work in one SVG's viewBox space (getBBox×getCTM)
  when you must inspect geometry, or (better) analyze the raw file offline (`~/dev/elf-lab`).
