**SCR/CO catalyst systems** (exhaust scrubbers for gas-turbine mini-power-plants; TITAN PGM

**Not a CAD tool** — speed + clarity over precision. Real multimillion-dollar bids depend on

## Open follow-ups / next steps

1. **Bug #1 — black blobs (BLOCKED at post-render, needs PARSER-LEVEL).** The blobs are solid-hatch /
   solid nozzle symbols — ultra-dense clusters of thousands of tiny stroke segments (densest 8-unit
   cell = 2166 lines+paths), all `fill:none` (the "solid" look is packed strokes). Tried 5 removal
   approaches, all failed: pixel hit-test (fails — `fill:none` not hittable + screenshot px ≠ CSS px),
   small-bbox coverage, NS/FS-label proximity (labels offset from shapes), hiding giant >10k-char paths
   (517 — not the blobs), hiding dense cells >600 els (25418 — not the visible blobs). Root: LibreDWG's
   SVG carries NO `layer` attr, NO fill, NO color signature. **Clean fix = filter HATCH/SOLID entities
   or emit layer classes inside `dwg_to_svg()` in `parser.ts` (investigate `@mlightcad/libredwg-web`
   API).** Density-threshold hiding is fragile (misses small nozzle solids OR risks hiding real
   equipment detail in a bid drawing). See memory `live_qa_session4`.
2. **Deep #3 scoping.** The quick guards only catch GROSS width edits; a sub-2.5× width edit on a
   stacked elevation still subtly ovals neighbors (they share the X-band). Real fix: hold neighbors
   RIGID and scope the scale to the target component. Now more feasible since #2 produces real
   component geometry. Package-B-class (see `package_b_parked`).
3. **Commit / push** — only when Mike asks. Branch is 10 ahead of `origin/wip`; never `main`. Revert
   the `auth.ts` dev-login before any commit (already reverted). Decide whether to keep the dev-only
   `no-store` fetch (prod-safe, `NODE_ENV`-gated) or drop it.
4. **Production AI** still gated: prod uses the Gateway (needs a card) OR set `ANTHROPIC_API_KEY` in
