## BLUF

EnergyLink FLEX (ELF) is a **sales-configuration tool** for an engineering firm that sells
**SCR/CO catalyst systems** (exhaust scrubbers for gas-turbine mini-power-plants; TITAN PGM
130 base design). A salesperson takes a base CAD drawing and adapts it (taller stack, bigger
silencer, wider duct) to a new customer's site, producing a drawing "good enough for a sales
sign-off." **Not a CAD tool** — speed + clarity over precision. Commercial product; real
multimillion-dollar bids depend on the output being correct.

Over two sessions we went from "is the model smart enough?" to a **proven, committed engine**.
The bottleneck was never the model — it was the **data pipeline**. Session 1 (offline lab)
found the root causes and proved the whole engine. Session 2 ported it all into the running
app and built the hardest remaining piece (per-view spatial scoping) with a full
brainstorm → spec → plan → subagent-driven build, including a safety net that guarantees a
corrupt drawing is never shown to a customer.

**Everything offline-provable is DONE, verified, and committed (3 commits, not pushed).** The
only thing between here and customer-ready is **AI creds** (expired) for the live run +
in-browser QA.
